# موقع مقهى هقَّوة — خطوات التشغيل والرفع (Supabase + GitHub Pages)

الموقع يعمل على **GitHub Pages** (مجاني)، والقاعدة وتسجيل الدخول والصور على **Supabase** (مجاني للاستخدام العادي).
قبل ربط Supabase يعمل الموقع بـ"وضع المعاينة" (التصميم والمنتجات التجريبية فقط).

## محتويات المجلد
```
index.html        الموقع
admin.html        لوحة التحكم  (الرابط: موقعك/admin.html)
supabase.sql      سكربت إعداد القاعدة ← تشغّله مرة واحدة (الخطوة 2)
js/config.js      ← هنا تلصق بيانات Supabase (الخطوة 4)
assets/           الشعار  ← ضع هنا شعار كيتا باسم keeta.png
css/  js/         التصميم والكود
```

## الخطوة 1 — إنشاء مشروع Supabase
1. ادخل https://supabase.com ← **Start your project** ← سجّل بحساب GitHub أو بريدك.
2. **New project** ← الاسم `haqwa` ← اختر كلمة مرور قوية لقاعدة البيانات واحفظها ← اختر أقرب منطقة ← **Create new project** (يأخذ دقيقتين).

## الخطوة 2 — إنشاء الجداول والصلاحيات
1. من القائمة اليسرى: **SQL Editor** ← **New query**.
2. افتح ملف **supabase.sql**، انسخ محتواه كاملاً والصقه ← اضغط **Run**.
3. يجب أن تظهر رسالة Success. (هذا ينشئ الجداول، وصلاحيات الأمان، وحاوية الصور `media`، والتحديث اللحظي.)

## الخطوة 3 — إعدادات تسجيل الدخول
من **Authentication**:
1. **Sign In / Providers** ← **Email**: فعّله، و**أوقف خيار "Confirm email"** (مهم جداً حتى يعمل دخول الموظفين باسم المستخدم).
2. **Sign In / Providers** ← **Google** (لزوّار الموقع):
   - افتح https://console.cloud.google.com ← أنشئ مشروعاً ← **APIs & Services ← OAuth consent screen** (External، املأ الاسم والبريد وSave).
   - **Credentials ← Create credentials ← OAuth client ID ← Web application**.
   - في **Authorized redirect URIs** ضع الرابط الظاهر لك في صفحة Google داخل Supabase (شكله `https://xxxx.supabase.co/auth/v1/callback`).
   - انسخ **Client ID** و**Client Secret** والصقهما في Supabase ثم فعّل Google وSave.
3. **URL Configuration**: ضع في **Site URL** رابط موقعك على GitHub Pages (الخطوة 6)، وأضفه أيضاً في **Redirect URLs** مع `/**` في آخره، مثال:
   `https://اسمك.github.io/haqwa/**`

## الخطوة 4 — ربط الموقع بـ Supabase
**Project Settings ← API**: انسخ **Project URL** و**anon public key** والصقهما في الملف **js/config.js** مكان كلمات PASTE.
(مفتاح anon عام وآمن لأن الحماية في صلاحيات القاعدة. **لا تستخدم أبداً مفتاح service_role** في الموقع.)

## الخطوة 5 — الرفع على GitHub
1. فك الضغط على جهازك، ثم افتح مستودعك على GitHub ← **Add file ← Upload files**.
2. اسحب **كل محتويات** المجلد (الملفات + المجلدات css و js و assets) ← **Commit changes**. (إذا رفعت النسخة القديمة سابقاً فسيتم استبدال الملفات المتشابهة؛ احذف `firestore.rules` يدوياً إن كان موجوداً.)
3. **Settings ← Pages** ← Source: **Deploy from a branch** ← Branch: **main** و **/(root)** ← Save.
4. رابط موقعك يظهر بعد دقيقة: `https://اسمك.github.io/اسم-المستودع/` — ارجع إلى الخطوة 3 (URL Configuration) وضعه إن لم تفعل.

## الخطوة 6 — إنشاء حساب المدير
افتح `رابط-موقعك/admin.html` ← سيظهر نموذج **إنشاء حساب المدير** (مرة واحدة فقط): الاسم + اسم المستخدم + كلمة المرور.
بعدها من لوحة التحكم:
- **المنتجات ← بيانات تجريبية** لإضافة 3 منتجات وعرض للتجربة.
- **الموظفون ← إنشاء حساب موظف**: الاسم + صورة (اختيارية) + اسم مستخدم + كلمة مرور. الموظف يدخل من نفس الصفحة ويتعامل مع الموقع كاملاً، لكن لا يرى تبويب الموظفين ولا ينشئ حسابات. المدير يستطيع أيضاً **تغيير كلمة مرور** أي موظف أو تعطيله أو حذفه.

## شعار كيتا
أضف الملف إلى مجلد `assets` باسم **keeta.png**. إلى أن تضيفه يظهر اسم Keeta كنص.

## ماذا تعدّل من لوحة التحكم
| التبويب | الوظيفة |
|---|---|
| الطلبات | استقبال طلبات الزوار مباشرة وتغيير حالتها (جديد ← قيد التحضير ← جاهز ← مكتمل) |
| المنتجات / العروض | إضافة، تعديل، صورة، إخفاء/إظهار، حذف، ترتيب |
| المعرض | رفع صور (عدة صور دفعة واحدة)، عنوان، حجم، إخفاء، حذف، ترتيب |
| النصوص | تعديل أي نص بالعربي والإنجليزي وتغيير حجمه أو إخفاؤه أو استرجاعه |
| الشعار والهوية | الشعار وحجمه، الشعار الثانوي للمناسبات (إظهار/حذف/تغيير الحجم)، اسم الموقع وحجمه، **رفع ملف خط**، إخفاء أقسام كاملة |
| الموظفون | (للمدير فقط) إنشاء/تعطيل/حذف الموظفين وتغيير كلمات مرورهم |
| سجل النشاط | "أحمد قام بكذا بتاريخ كذا والساعة كذا" لكل عملية، ولا يمكن تعديله أو حذفه |

## ملاحظات
- الصور والخطوط تُرفع كملفات حقيقية إلى Supabase Storage (الخطة المجانية 1GB). الصور تُصغَّر تلقائياً.
- إذا لم يُستخدم مشروع Supabase المجاني لمدة أسبوع يتوقف مؤقتاً؛ يعاد تشغيله بضغطة من لوحة Supabase (الدخول المنتظم يمنع ذلك).
- لتغيير روابط التواصل أو الفروع افتح `js/defaults.js` في آخر الملف (`HQ_LINKS`).
- الأرقام المتحركة (24 / 2 / 7 / 365) نصوص قابلة للتعديل من تبويب النصوص.
- الأسعار والأوصاف التجريبية للتجربة فقط — عدّلها قبل الإطلاق.
